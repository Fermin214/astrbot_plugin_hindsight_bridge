模型配置

?

大语言模型（LLM）：用于 Hindsight 的记忆提取（Retain）、整合（Consolidation）和反思（Reflect），包括知识页生成与更新；不负责机器人的日常回复。

嵌入模型（Embeddings）：将文字转换成向量，供记忆召回（Recall）按含义查找。请从 AstrBot「模型供应商 → 嵌入」中选择。

重排模型（Reranker）：对检索结果再次排序，可选。

这些模型供 Hindsight 使用，从 AstrBot 已有供应商中选择。AstrBot 的日常聊天模型在宿主设置中管理。

验证、整理、检索和知识页更新可能产生模型调用费用，请确认供应商计费。

移除用户并保存后，撤销该用户的记忆访问权限，已有记忆保留。重新添加或换机器人账号后，请再次确认授权。

服务升级与卸载

升级 Hindsight 到 1.2.0

1.1.0 仍受支持，可以继续使用。升级保留原记忆、身份和模型设置。

1. 暂停所有用户的记忆保存和查询，等待已有记录处理完成。普通聊天继续，但暂停期间的新聊天不会保存。其他客户端和官方面板也须停止写入。

2. 备份插件业务数据、最新控制数据及插件配置。下方命令另会备份服务配置、模型设置和数据库，保存在原安装目录旁的备份目录。

升级命令

在原服务器、原安装路径执行，不要先卸载。使用自定义 HINDSIGHT_INSTALL_ROOT 时保持原值。失败时不要恢复保存和查询，保留备份并按备份与恢复指南处理，不直接改回旧镜像。

3. 执行成功后点击「核对升级结果」。确认旧记忆可用，再点击「解除升级造成的暂停」，一次恢复受影响用户；原记忆模式及升级前已有的暂停保留。

暂不升级

仅适用于服务仍为 1.1.0：解除这次升级新增的暂停，保留原有暂停及记忆模式。已复制的升级命令不会撤销，放弃后请勿再执行。

修复配套服务

重新部署 1.2.0 服务，保留记忆、模型和凭据；不用于从 1.1.0 升级。

卸载配套服务

删除这套服务及全部记忆数据。插件本体需在 AstrBot 插件面板单独卸载。

保存进度怎么看？

这里显示聊天记录交给 Hindsight 的保存进度。「已保存」表示保存任务已完成；出现失败时，先按错误提示处理，再点击「重试失败记录」。

检索与保存分开执行。检索超时只表示该次没有读取到记忆，不表示新聊天保存失败；是否保存，以这里的任务结果为准。

什么时候暂停保存和查询？

去官方面板更正、删除记忆或导入备份前，先暂停这个用户的记忆保存和查询，包括手动查看。普通聊天继续，但暂停期间的新聊天不会保存。Hindsight 已接收的记录继续处理。

1. 先等要保留的聊天记录保存完成。失败记录修复后重试。

2. 点击「暂停保存和查询」，再点击「检查暂停进度」，等到显示「可以修改记忆」。

3. 打开下方「官方管理地址」，按记忆库 ID 选择 Bank，完成更正、删除或导入。

4. 回到这里点击「恢复原记忆模式」。原模式为「暂停保存和自动使用」或「只自动使用已有记忆」时，仍按原模式运行，不会自动开启保存。

还有待保存记录怎么办？

想保留这些记录，请在暂停前等它们保存完成。决定放弃时，勾选「放弃尚未发送或保存失败的记录」，再点击「暂停保存和查询」；已经暂停时再次点击即可。放弃的记录无法恢复。

什么时候清空全部记忆？

想让这个用户的长期记忆从头开始时，使用「清空此用户的记忆」。确认后删除其全部长期记忆、知识页及来源材料，AstrBot 聊天记录保留。

这里查看聊天的保存进度。更正、删除或导入前，先暂停保存和查询，完成后恢复原记忆模式。

保存失败时，先按错误提示处理，再点击「重试失败记录」。暂停与恢复步骤见右上角问号。

知识页（Knowledge Page）

?

它与普通记忆检索有什么区别？

记忆召回（Recall）按问题查找相关记忆。知识页（Knowledge Page）是 Hindsight 从记忆中按主题生成的文档；插件可把所选短页提供给聊天模型参考。例如：从聊过的内容中整理「项目目标及约束」，供新会话参考。

怎样准备？

打开上方官方管理地址，按「记忆库 ID」选择 Bank。进入 Knowledge（知识）→ Pages（知识页），在 Knowledge Base（知识库）点击 New page（新建知识页），填写名称和 Source query（源查询，即希望此页回答的问题），创建后等待正文生成。

需要缩短正文时，打开该知识页的 Mental model options（心智模型选项），点击 Edit（编辑），在 General（概览）调低 Max Tokens（最大令牌数）并保存。重新打开「心智模型选项」，在操作菜单点击「立即完整刷新」，再确认「执行完整刷新」，等待生成并核对正文长度；普通手动刷新可能保留原正文。

已有记忆没有标签时，创建页的标签留空。生成和刷新可能产生模型费用。

回到这里点击「获取知识页列表」，选择一份知识页，勾选「聊天时使用所选知识页」，再点击「保存知识页选择」。使用者发送 /hindsight background 核对正文；创建和更新仍在官方面板操作。

关闭、更新和超限

点击「停止聊天时使用知识页」后，不再向聊天模型提供知识页，已选知识页和手动查看保留。「暂停保存和自动使用」模式停止自动使用；点击「暂停保存和查询」后，手动查看也会暂停。

内容是否过期显示「未知」时，请在官方面板核对内容是否已更新。修改或删除前先暂停保存和查询。

整页太长或读取超时时，该次聊天不使用知识页，记忆检索仍按所选记忆模式执行。超长内容请在官方面板调整为短页后再试。

可选：让机器人在新会话中参考一份简短资料，例如项目目标和约束。默认关闭，记忆检索按所选记忆模式运行。

Hindsight 从已有记忆按主题生成知识页。插件只选择和读取，不创建或更新正文。
