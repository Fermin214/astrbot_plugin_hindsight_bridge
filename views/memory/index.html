安装方式

适用于运行 AstrBot 的 Linux 主机，需已安装 Docker 和 Compose。命令会自动配置服务与网络；AstrBot 使用 Docker 时无需开放额外端口。

安装只部署服务，模型在安装完成后选择。

在服务器上安装一次

在运行 AstrBot 的 Linux 服务器终端粘贴一次，完成后回到这里检查连接并配置模型。

命令含这套服务的连接凭据，仅在生成时展示；不包含模型密钥。
