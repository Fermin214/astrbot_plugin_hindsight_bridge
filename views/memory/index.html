    备份与恢复

    1. 停止写入

      暂停所有写入，等待任务结束。手工备份时停止 Hindsight，保留数据库运行。

    2. 备份插件数据

      在 AstrBot 中执行，替换路径与备份时间。输出目录使用新目录。

      另存插件配置和 setup.json。

    3. 备份配套服务数据和配置

      导出 PostgreSQL 数据库，保存部署文件和 models.json。

    4. 核对恢复与保存副本

      在独立环境检查备份，并保存异机副本。

      恢复检查通过后，再恢复写入。

      恢复业务快照时沿用最新控制库、原 service_id 和账号对应关系。

    升级 Hindsight

    1. 暂停插件读写

      暂停期间的新聊天不会保存，普通聊天继续。

    2. 备份并执行升级

      备份插件配置、业务库和最新控制库。

      在原服务器、原安装目录执行。失败时保持暂停并恢复备份。

    3. 核对并结束升级

      确认版本和旧记忆后恢复写入。

    暂停状态

    删除待发送和失败的记录，无法撤销。
