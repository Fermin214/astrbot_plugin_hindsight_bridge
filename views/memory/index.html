    备份与恢复

    1. 暂停 Bridge 读写

      暂停插件读写，等待保存任务结束。

    2. 备份 Bridge 数据

      在 AstrBot 的 Python 环境执行，替换安装路径、控制目录和备份时间。输出目录使用新目录。

      另存插件配置和 setup.json。

    3. 备份配套服务

      停止配套 Hindsight 的写入，等待任务结束。导出 PostgreSQL 数据库，保存部署文件和 models.json。命令见操作文档。

    4. 检查恢复

      在独立环境检查 Bridge 备份，并保存异机副本。恢复业务快照时沿用最新控制库、原 service_id 和账号对应关系。

    Bridge 备份内容：业务数据、最新控制库和插件配置。

    Hindsight 数据由服务管理员按原部署方案备份与恢复。

    升级 Hindsight

    1. 暂停插件读写

      暂停期间的新聊天不会保存，普通聊天继续。

    2. 备份并执行升级

      备份插件配置、业务库和最新控制库。

      在原服务器、原安装目录执行。失败时保持暂停并恢复备份。

    3. 核对并结束升级

      确认版本和旧记忆后恢复写入。

    暂停状态

    删除待发送和失败的记录，无法撤销。
