# Hindsight Bridge

连接自托管 Hindsight，让 AstrBot 在新会话中也能记得你。

正常聊天，插件就会把 QQ、微信 ClawBot 私聊文字交给 [Hindsight](https://github.com/vectorize-io/hindsight) 整理成长期记忆，并在之后的聊天中自动查找相关内容。不同用户的记忆分开保存。

在 AstrBot 插件页配置连接、添加使用者和调整记忆模式；在 Hindsight 官方管理页面（Control Plane）浏览、搜索和管理记忆。可以连接已有 Hindsight，也可以通过安装向导部署配套服务，复用 AstrBot 已配置的模型。

## 安装

支持 **Linux 服务端**、**AstrBot 4.29.1 及以上的内置执行器 `local`**和 **Hindsight 1.1.0 / 1.2.0**。QQ 私聊可使用 OneBot v11（`aiocqhttp`），或官方机器人 C2C 的 WebSocket（`qq_official`）与 Webhook（`qq_official_webhook`）入口；微信使用原生 [ClawBot](docs/WEIXIN.md)（`weixin_oc`）私聊。默认在同一台服务器部署 AstrBot 与 Hindsight，可连接已有服务，也可使用配套安装器。版本和消息限制见 [兼容范围](docs/SUPPORT.md)。

1. 在 AstrBot 打开 **插件管理 → 安装 → 从链接安装**，粘贴：

   ```text
   https://github.com/Fermin214/astrbot_plugin_hindsight_bridge
   ```

2. 安装完成后打开 **Hindsight Bridge 插件详情 → 记忆管理 → 插件设置**。
3. 选择安装方式：生成配套服务安装命令，在运行 AstrBot 的 Linux 主机执行；已有 Hindsight 1.1.0 或 1.2.0 则填写服务 API 地址、API Key 和官方管理地址。
4. 配套组件安装完成后，在设置中选择记忆处理模型与向量模型，可选重排模型，点击 **保存并连接**。页面完成验证、启动和插件接入后显示已连接。
5. 进入 **用户与记忆**，点击 **添加用户**，选择机器人实例：OneBot 填 QQ 号，QQ 官方机器人或微信 ClawBot 填私聊 `/sid` 返回的用户 UID，再核对并确认机器人身份。

配套安装的主机需已安装 Docker Engine 和 Compose v2，支持 AstrBot 原生运行，以及 Docker 自定义 bridge、默认 bridge 和 host 网络。保存设置并确认机器人身份后，正常聊天即可。

配套部署的记忆处理模型与向量模型从 AstrBot 供应商列表选择，无需重复填写模型地址和 Key。嵌入模型用于查找相关记忆，与平常聊天的模型用途不同；缺少时，向导会提示去 AstrBot「模型供应商 → 嵌入」添加。重排模型可不选。连接已有服务时，模型由该服务的原部署配置管理。

两种部署的管理方式如下：

| 能力 | 配套部署 | 连接已有服务 |
| --- | --- | --- |
| 保存与检索、知识页选择、用户管理 | 在插件中操作 | 在插件中操作 |
| 记忆预算、等待时间、查询与队列参数 | 在插件面板中调整 | 在插件面板中调整 |
| 模型配置 | 在插件中选择 AstrBot 模型并应用 | 由服务管理员负责，插件不提供 |
| 服务备份与升级 | 插件提供备份步骤与升级命令，升级后核对结果 | 由服务管理员负责，插件不提供 |
| 重新部署与卸载服务 | 插件按专属安装记录生成命令 | 由服务管理员负责，插件不提供 |

**测试服务连接** 检查记忆 API 和认证。配套模型管理还需核对安装记录与管理接口；官方 Control Plane 用于管理记忆内容。

详细步骤及常见问题见 [安装指南](docs/INSTALL.md)。手工管理后端见 [Linux 部署说明](deploy/README.md)。

## 从 0.1.x 升级

升级前备份插件业务数据和最新控制数据，步骤见 [备份与恢复](docs/DATA-MAINTENANCE.md)。在 AstrBot 更新并重载插件；页面提示确认账号时，核对机器人身份后确认即可。

新配套安装使用 Hindsight 1.2.0。配套服务升级按 [服务升级步骤](docs/DATA-MAINTENANCE.md#升级-hindsight-服务) 操作，更新插件本身不改变 Hindsight 服务。连接已有服务只使用接口，不管理其模型、部署和运维。

使用 QQ 官方机器人时，在用户与记忆中添加私聊 `/sid` 返回的 OpenID。保持原实例、AppID 和使用者不变，在 WebSocket 与 Webhook 之间切换可继续使用原有记忆；连接方式由 AstrBot 和 QQ 开放平台配置。

## 使用与管理

日常聊天无需发送记忆命令。在 **用户与记忆** 中选择用户，点击 **读写记忆 / 只读记忆 / 停用记忆** 直接切换模式，查看已保存、待保存、失败数量和最近检索时间。移除用户后立即撤销访问权限并移出选择器，已有记忆保留。

在 **插件设置 → 连接与访问** 复制管理地址，在浏览器打开官方 Control Plane。复制 **Bank ID**，登录后找到对应 Bank，直接浏览、搜索和管理内容，不需要暂停插件或服务。**Bank 是按机器人和用户隔离的记忆库**，首次保存聊天时自动创建。远程访问与登录密钥的获取方式见 [部署说明](deploy/README.md#五打开官方-control-plane)。

可选 **聊天知识页**：选择最多 8 篇 Hindsight 按主题生成的文档，调整顺序，让机器人按预算参考完整页面；选择与排序直接保存，每页显示实际使用结果，**不使用知识页** 停止自动传递。创建与更新在官方 Control Plane 完成，步骤见 [知识页说明](docs/USAGE.md#可选知识页)。

**细节记忆** 默认使用 **自动召回**，也可在模型与会话支持工具时选择 **按需工具**，由 AstrBot Agent 决定何时搜索知识页、分段读取原文、查找事实或查看来源和最近版本。长页无需全部放入自动参考预算；工具查询与结果可能保存在 AstrBot 会话及日志中，清空 Bridge 记忆会保留这些宿主记录。操作和额度见 [按需记忆工具](docs/USAGE.md#按需记忆工具)。

可在同一区域独立开启 **Reflect**，让 Hindsight 综合记忆回答复杂问题，默认关闭，不替代自动召回。Reflect 会额外调用记忆处理模型；执行结果不明的请求会阻止相关旧记忆库完成清空。等待、来源及恢复条件见 [Reflect](docs/USAGE.md#reflect)。

在 **插件设置 → 连接与访问** 复制 **Hindsight 管理地址**，到浏览器打开，按 Bank ID 找到记忆库，创建和刷新知识页。

在 **插件设置 → 记忆与知识页** 调整长度、超时、查询、分词、队列容量和排除前缀，点击 **保存**。知识页显示 token 用量与上限；调整上限后点击 **刷新知识页**。

**清空记忆** 会删除所选记忆库的全部长期记忆、知识页及其历史、来源材料和待保存记录，需确认删除范围，无法撤销。清理完成后重新选择 **读写记忆**，AstrBot 自身的聊天记录保留。

配套服务有适用更新时，页面顶部显示可忽略的升级横幅；升级尚未完成时保留进度入口。升级或故障留下的读写暂停通过 **查看暂停状态** 处理，检查通过后 **解除读写暂停**，原记忆模式保持。完整步骤见 [使用指南](docs/USAGE.md)。

使用者也可以在自己的 QQ 或微信 ClawBot 私聊中发送：

| 想做什么 | 命令 |
| --- | --- |
| 查看记忆 | `/hindsight view` |
| 查看已选知识页 | `/hindsight background [序号]` |
| 停止记录新内容，继续使用已有记忆 | `/hindsight readonly` |
| 暂停记录和自动使用记忆 | `/hindsight pause` |
| 开启保存和自动使用记忆 | `/hindsight on` |
| 清空自己的记忆 | `/hindsight forget`，再按回复确认 |

插件总开关位于 AstrBot 插件面板。卸载配套服务时，在 **插件设置 → 服务管理** 生成卸载命令；该操作会删除整套配套服务及其中所有用户的记忆数据。插件本体通过 AstrBot 卸载入口移除。

## 记忆范围

记录已启用账号的私聊文字，以及 AstrBot 保存到会话历史中的机器人最终文字回复。群聊、图片、语音、引用、转发和命令不自动记录；安装前的聊天记录不自动导入。

新消息会在后台整理，不会立刻出现在列表中。服务暂时不可用时普通聊天仍可继续，待办会在连接恢复后继续处理。

对话内容会发送到所连接的 Hindsight 及其模型服务。查看和搜索显示官方服务中的记忆，更正也在官方页面完成。
