## 回滚与验收证据

可确认两次功能撤回。`708a543` 将内容管理交还 Hindsight 官方面板，`34b8b58` 撤掉已有服务的升级提醒和入口。0.2.7 的旧业务库恢复、#19 降到 0.3.5 再升级均在独立环境验证遗忘后的数据边界。#13 关闭于合并前。公开 Git、PR 和验收记录里未发现整版生产回滚的证据。

0.3.0 的真实模型样本有四项通过，完整脚本的 `complete` 仍为 `false`。末项使用了会被 Hindsight 自身整合改变的记忆总数，后续改查 Bridge 队列和实际 Retain 请求。原样保留分项和整体结果，能让后续修改复用已经证明的部分。历史范围可用 `git log --no-merges v0.3.6` 与各 PR 的 Commits 页交叉核对。
