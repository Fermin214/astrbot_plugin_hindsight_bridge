# 安装与管理设计

## 页面结构

面板提供「用户与记忆」和「插件设置」两个标签。「用户与记忆」以紧凑选择器管理用户，依次显示身份、记忆模式、记忆内容与状态，末尾提供移除和清空。「插件设置」按模型配置、连接与访问、服务管理纵向排列，全部展开。首次缺少服务连接时显示安装或连接引导；完成后默认进入「用户与记忆」，安装引导隐藏。

模式和知识页选择直接保存，每个按钮说明自己的动作。界面不设置问号帮助、折叠内容或密钥展示。删除确认直接说明数据范围与后果；操作错误就地说明原因和下一步。

记忆内容的浏览、搜索、更正、删除、Bank 管理和原生导入导出由独立打开的 Hindsight 原生 Control Plane 提供。插件不实现内容列表、详情、更正表单或下载页面。QQ view/show/export 只提供本人范围内的官方只读 API 转发。

支持 Linux、AstrBot 4.29.1 及以上版本的内置执行器 `local`、Hindsight 1.1.0 / 1.2.0，以及 OneBot v11（`aiocqhttp`）和 QQ 官方 WS/Webhook 的 C2C 私聊纯文字，默认同机部署。模型配置使用协议适配、配置管理器和原子回退。

配套新安装固定使用 1.2.0 Slim。服务进程等待 75 秒，容器退出宽限为 90 秒，覆盖上游启动脚本的 60 秒退出等待。配套服务通过保留安装身份、凭据、模型设置卷和数据库的专用升级命令升级；插件更新本身不操作服务容器。配套升级和备份步骤见 [备份与恢复](DATA-MAINTENANCE.md#升级-hindsight-服务)。

插件总开关使用 AstrBot 插件面板的启停。空配置可加载，完成配置前不采集；关闭插件通过终止钩子停止队列与采集并释放资源。

## 安装与模型配置

Linux 配套安装器封装 Hindsight 原生启动与配置，部署数据库、Hindsight 进程管理器、匹配版本的官方 Control Plane 及独立数据卷，不修改 AstrBot 或 Hindsight 的上游源代码。连接凭据由后台自动生成和保存，安装命令不包含模型密钥。含凭据命令由管理员显式生成，在复制、关闭、离开设置或隐藏页面后清除展示。初次安装使用安装引导；已有安装记录时从「服务管理 → 重新部署」重新生成命令，不依赖服务在线。安装目录存在则沿用配置与数据；完全卸载后重新安装，不恢复已删除数据。

配套安装模式下模型选择区始终显示，复用 AstrBot 已配置的对话、嵌入和可选重排供应商。页面只显示模型标识、名称与适配结果。保存时先检查配套服务；尚未安装则提示执行安装命令。后台读取配置并探测实际向量维数，先验证配套服务安装身份，再经鉴权管理接口提交模型配置。服务侧验证模型、启动 Hindsight 并保存私有配置；失败时恢复先前配置。

管理器只能控制本容器的 Hindsight 子进程与自己的设置卷，不需要 Docker socket 或主机配置写权限。模型保存独立于安装，日常修改不重新生成安装命令。嵌入协议、地址、模型、参数或维数变化需要向量迁移；密钥轮换不改变嵌入身份。

对话协议支持 OpenAI Chat、Responses、Anthropic 与 Gemini。百炼原生、Gemini、Ollama 嵌入及百炼原生、TEI 重排等请求通过同容器的内部协议转换处理。转换保留地址、认证、代理、维度发送方式与请求参数，不记录模型正文、密钥或上游错误。

已有 Hindsight 通过 API 地址和服务密钥连接，并单独填写 `control_plane_url`。插件仅调用记忆 API，不提供该服务的模型配置、备份、升级、重新部署和卸载，也不提供对应操作步骤或命令。公开接口存在不构成扩大管理范围的依据。

配套管理以插件安装记录和连接地址确定范围，模型应用还须验证管理接口的安装标识与协议。切换到已有服务后，旧配套安装记录不能开启模型和服务管理；后台不查询旧配套管理接口，也不展示其密钥读取命令或模型任务。未配置连接时可继续完成配套安装和模型设置。

旧配套升级记录不阻断已有服务的连接、用户和记忆操作。实际读写暂停保留，按 Bank 核对身份、原记忆库与任务后逐个显式解除，原记忆模式保持。

控制库中的清空记录使旧 Bank 对应的升级快照与批量暂停来源失效，实际读写暂停继续保留。恢复配套连接后，个人恢复仍按原流程核对；重新开始升级时保存新的 Bank 与代次，不复用已经清空的旧快照。

「保存并连接」提交后台任务，页面查询模型验证、应用与插件接入进度；相同请求标识重复提交时复用任务结果，处理中相同模型选择复用任务。接入记录持久化到 `setup.json`，插件重载后根据目标模型指纹、服务状态与已保存连接恢复。模型成功但连接提交失败时保留原插件配置，重试不重复应用已就绪模型。插件退出时取消任务并释放资源，不在取消后重新初始化。

配套 API 地址只读，连接密钥来自安装记录，不保留独立保存连接按钮。「保存管理地址」只写浏览器访问地址，不验证模型、重启服务或切换连接。已有服务模式保留「保存连接」和「测试服务连接」；切换方式须持久化，旧安装记录没有方式字段时按地址和凭据判断归属。

### 安装器返回字段

`core.installer.installation()` 返回以下字段：

| 字段 | 用途 |
| --- | --- |
| `command` | 含部署凭据的安装命令，按页面生命周期清除展示 |
| `api_url`、`management_url` | 插件连接 Hindsight API 与配套模型配置接口的地址 |
| `control_plane_url`、`browser_url` | 官方管理地址；优先使用显式设置，否则使用安装配置中的地址或环回端口 |
| `control_plane_key_file` | 登录密钥所在 `.env` 路径，使用 `$HOME` / `HINDSIGHT_INSTALL_ROOT` 表达安装根目录 |
| `control_plane_key_env` | 固定为 `HINDSIGHT_CP_ACCESS_KEY` |

除 `command` 外，上述字段不含明文密钥。页面 bootstrap 的 `control_plane_key_command` 根据合法安装标识生成读取命令，不读取或返回登录密钥；命令在安装服务器执行。

## 独立官方管理访问

`config.control_plane_url` 是管理员浏览器可访问的「Hindsight 管理地址」，与服务侧 `api_url` 分开保存在「插件设置 → 连接与访问」。管理员复制地址后在浏览器打开官方面板，用户页提供可复制的 Bank ID。普通内容操作不需要暂停插件或服务，也不改变记忆模式。Control Plane 独立登录，地址中不携带凭据，插件页不展示登录密钥。

有域名使用独立 HTTPS 入口，无域名使用 SSH 隧道连接服务器环回端口。代理、登录密钥和环回端口见 [部署说明](../deploy/README.md)。

## 连接、保存与暂停状态

页面可见时每隔约五秒获取状态，请求失败后逐步延长至三十秒，恢复后继续正常更新。隐藏页面暂停查询，返回页面后恢复。自动获取状态保留未保存的连接、模型选择、记忆参数和添加用户表单。模式与知识页选择即时保存。

页面连接 AstrBot 限时 10 秒，获取初始状态限时 15 秒；首屏失败时可重新加载插件页面，重新建立宿主 SDK 连接。保存和查询暂停状态在首屏完成后读取，每次限时 15 秒。缺少连接配置时指出具体缺项。服务连接状态独立展示；用户选择、记忆模式、保存进度、最近检索结果和暂停异常集中于「用户与记忆」，随所选用户更新。`recall_timeout` 默认 10 秒，允许 0.2 到 30 秒，升级时保留已保存的值。

「用户与记忆」只从配置名单生成用户选择器；移除立即撤权并移出选择器，保留 Bank。名单写入成功后同步页面名单与修订号，后续状态读取失败不会回退到旧名单。真实旧机器人记忆在同一用户的「记忆库」选择器中显示机器人账号，不把离线或待确认身份笼统标成历史用户。

知识页长度检查与目录更新标记分开显示，不覆盖上次聊天的使用结果。选择时核对原生页与模型正文一致，超限或空正文仍可保存引用，但明确显示无法使用的原因和超出的上限；重新打开页面或点击「重新检查长度」时读取所选正文重算长度，不保留旧正文。目录标记不保证正文最新。

「记忆与知识页设置」在两种接入方式下均可使用，常用项覆盖独立页面上限、共享 token/字符上限及两项等待时间，高级项覆盖查询长度、分词编码、队列数量与容量及命令前缀；默认预算与等待不增加。参数独立保存，与标准插件配置共用存储，校验修订后直接应用，无需重连、保存模型或重载。表单分别展示保存值和运行值，轮询保留草稿，冲突时重新加载记忆设置；部署与迁移字段只读展示并提供备份与迁移说明。

模式为「读写记忆」「只读记忆」「停用记忆」，点击后提交，成功才更新选中状态。「聊天知识页」自动读取已有列表，最多选择 8 篇；添加、排序和移除立即保存，每篇分别显示长度检查、目录更新标记和聊天使用结果。「不使用知识页」停用全部引用，保留顺序，不删除官方内容。只在已确认范围读取元数据，浏览器只提交有序 page ID，不能指定 Bank/model ID；服务端从原生目录确认映射，保存比较配置、owner 与选项修订。切换用户或 Bank/修订变化使旧列表失效，迟到响应不能覆盖新用户。

Hindsight 内容名称沿用 Control Plane：Bank 为记忆库，World Facts / Experience / Observations 为世界事实 / 经历 / 观察，Knowledge Page 为知识页，Mental Model 为心智模型。插件模型控件按用途命名为「记忆处理模型」「向量模型」「重排模型」。既有命令、API 路径和持久化键保持兼容。

用户页展示已保存、待保存与失败数量、最近检索时间及结果；已保存按插件确认成功的聊天材料计数，限定使用者与 Bank/代次，清空后重新计数。没有「所有记录已保存」空状态。模式选择不接管 Hindsight 的在途任务。内容管理直接在 Control Plane 完成，完整删除使用插件「清空记忆」同步作废旧来源和待办。

升级或故障留下的 Bank 读写暂停提供「查看暂停状态」对话框。移除用户后仍有暂停时保留全局提示，不将用户重新加入选择器。检查通过后「解除读写暂停」，失败时提供「重试检查」，存在可放弃记录才显示确认入口。未发送及已确认失败的记录可显式放弃，已发送但结果不明的记录继续阻止恢复。

同一范围轮询保留已确认结果，结果绑定 scope、Bank、owner/代次、连接与暂停起点，独立计时器在三十秒后使结果过期。身份变化、Bank 丢失、连接失败或新的真实任务结果立即使 ready 失效，迟到响应按请求代次丢弃。恢复操作继续由服务端实时核对，清理过时短期语境后解除暂停。

配套服务的可用升级以顶部横幅提示，忽略保存在插件安装记录中，按连接和目标版本隔离；升级未结束不能忽略。已有服务只显示实际版本，不显示升级横幅、升级指引或服务管理操作。

配套服务升级在 `setup.json` 的 `upgrade_pauses` 中记录连接、嵌入标识及升级新增暂停的 Bank、owner、代次和开始时间。已有暂停不加入批量解除范围，单独再次暂停的用户移出该范围。命令执行及升级核对通过后，在升级区域点击「解除升级暂停」；先完成全部范围与任务检查，再在同一控制库事务中解除这些暂停，记忆模式保持原值。旧记录缺少暂停来源时保留暂停，沿用个人恢复入口。服务仍为 1.1.0 时可从「暂不升级」解除升级新增的暂停；已复制命令仍由服务器执行，不因面板操作失效。

开始升级暂停时，先在控制库事务内创建暂停并保存来源，再提交控制库，最后重放到业务库；业务库不能记录尚未提交的控制修订。安装记录已保存而控制事务回滚时，重试按实际暂停重建来源记录。用户单独暂停时，先持久化移出批量解除范围的意图，再更新个人暂停，避免写入中断后被批量恢复。

既有 Bank 丢失时报 `bank_missing`，不能自动重建。恢复原 Bank 后通过「核对记忆库」查询原 Bank 是否存在，核对 owner、代次、修订与连接后解除缺失标记；已有读写暂停仍需完成进度检查后显式解除。也可使用完整遗忘登记新 Bank；完整遗忘依靠独立控制日志、新代次和持续清理。恢复核对失败可触发全局暂停，由管理员按 [备份与恢复](DATA-MAINTENANCE.md) 手工恢复。

## 配置与消息边界

平台实例从 AstrBot 读取，包含适配器类型、账号提示和能力状态；用户 ID 全程使用字符串。添加用户后进入身份确认；「确认机器人身份」绑定 Dashboard 登录用户、当前机器人真实身份、配置修订及控制修订，不需要先发送消息。Bank 在首次保存记忆时自动创建。机器人离线或服务恢复期间保留用户入口，说明连接或恢复要求。

QQ 官方 WS/Webhook 的 AppID、AppSecret、事件订阅和回调连接由 AstrBot 管理；插件只选择既有实例并保存用户 OpenID。原生机器人未完成认证时不激活授权。两种传输使用同一逻辑平台身份，不同实例不合并，切换 AppID 必须重新确认授权。

授权、撤权、单调接收下限和命令防重凭据保存在最新控制库，普通设置保存不能重绑。原实例换登录账号时，旧范围作为旧记忆库保留，管理员可处理已有暂停或清空；不提供模式切换和重试入口，不向新账号转移记忆。

消息时间跟随 AstrBot 全局 `timezone`，宿主未设置或值无效时按消息发生时刻使用系统本地时区。插件初始化和权限刷新时读取宿主设置，不受时间感知提示开关影响，不提供独立时区字段；已冻结的提交材料不随宿主设置改变。时间与身份提醒通过插件自身的结构化内容解析适配，宿主及其他插件的设置不参与写入。

## 卸载

配套服务管理直接展开，提供备份指南、适用升级、重新部署和卸载入口。卸载只确认删除范围并生成、复制命令，不要求在页面核对卸载结果。用户确认删除全部记忆数据后生成，复制、关闭或离开页面后清除展示，需要时重新生成。脚本检查安装标识、目录真实路径、服务列表和专属数据卷，移除该安装的容器、专属网络、数据卷与文件。外部网络、共享镜像、AstrBot 与 Docker 不属于删除范围。插件本体通过 AstrBot 的卸载入口移除。

## 数据与恢复

控制数据只写入 `data/plugin_data/astrbot_plugin_hindsight_bridge_control` 及其子目录，与业务数据保持分离。配置路径按真实路径核对，越界路径与符号链接在打开客户端和控制库之前拒绝。独立存储通过专属目录挂载接入；旧外部控制目录使用停机复制迁移，不静默切换为空控制库。

知识页列表加载与状态轮询不隐藏聊天使用结果。已选择、实际传入聊天和读取失败分别展示；结果只在内容通过最终身份与范围核对、加入临时请求后记录，并按聊天开始顺序更新，较早聊天的迟到结果不覆盖较新结果。身份、代次或确认绑定变化使选择失效，清空记录保留失效提示，重新选择后清除提示，不沿用旧引用。

配套设置卷保存模型参数和凭据，数据库卷保存记忆；备份须同时覆盖二者与插件身份、队列、控制状态。重新安装服务文件沿用身份和数据卷。内容更正以 Hindsight 原生结果为准，本地更正不参与召回、查看或导出。历史更正非空时，启动报告 `legacy_corrections_require_handover` 并保留数据，完成实际数据交接后继续。
