# 安装与连接

需要 Linux、AstrBot **4.29.1 及以上**的内置执行器 `local` 和 Hindsight **1.1.0 或 1.2.0**。QQ 私聊可使用 OneBot v11，或官方机器人的 WebSocket、Webhook。默认在同一台服务器部署 AstrBot 与 Hindsight，配套安装需要 Docker Engine 和 Compose v2。平台与模型支持见 [兼容范围](SUPPORT.md)。

## 一、安装插件

在 AstrBot 的 **插件管理 → 安装 → 从链接安装** 填写：

```text
https://github.com/Fermin214/astrbot_plugin_hindsight_bridge
```

依赖安装完成后，打开 **Hindsight Bridge 插件详情 → 记忆管理 → 插件设置**。设置用于连接、模型和服务管理；**用户与记忆** 用于添加用户、确认身份、选择模式和知识页、查看保存状态。

## 二、安装或连接记忆服务

### 安装配套服务

1. 选择 **安装配套服务**，点击 **生成安装命令**。
2. 点击 **复制命令**，在运行 AstrBot 的 Linux 主机终端执行。
3. 终端显示安装完成后，关闭命令窗口，回到模型配置区。
4. 选择 AstrBot 已配置的记忆处理模型与向量模型，可选重排模型，点击 **保存模型**。页面显示验证与启动进度，完成后点击 **保存连接**。

安装命令部署数据库、Hindsight 1.2.0 及其官方管理页面（Control Plane），自动生成连接密钥。网页登录密钥与插件连接服务的 API Key 分开使用。

需要重新部署 1.2.0 服务文件时，使用 **插件设置 → 服务管理 → 重新部署**，沿用现有配置和数据。从 1.1.0 升级须使用专用升级入口。

插件页显示实际后端版本。从 Hindsight 1.1.0 升级至 1.2.0 时，通过顶部升级横幅的 **查看升级** 完成暂停保存和查询、备份确认、升级命令生成和升级后核对，详见 [服务升级步骤](DATA-MAINTENANCE.md#升级-hindsight-服务)。1.1.0 仍受支持，不会自动升级。

配套服务的连接密钥由插件自动保存，无需填写。AstrBot 运行在 Docker 中时，服务接入 AstrBot 已有网络；主机开放的端口只监听 `127.0.0.1`，不能从管理员电脑直接访问。官方页面的反向代理、SSH 隧道、端口及密钥操作见 [Linux 部署说明](../deploy/README.md#五打开官方-control-plane)。

### 连接已有 Hindsight

选择 **连接已有服务**，填写服务 API 地址与 API Key，点击 **测试服务连接**，再 **保存连接**。连接测试检查记忆 API 和认证。

连接后可使用记忆保存与检索、知识页选择和用户管理。设置页显示「连接与访问」、连接状态和实际版本。模型配置、服务备份、升级、重新部署及卸载由服务管理员负责，插件不提供相关入口、步骤或命令。

服务端口通常为 `8888`；Hindsight 自带网页端口 `9999` 用于官方 Control Plane。在 Docker 桥接网络中，AstrBot 的 `127.0.0.1` 指向容器自身；使用 host 网络时指向宿主机回环地址。

在 **Hindsight 管理地址** 填写管理员浏览器可访问、且与服务版本匹配的 Control Plane 地址，网页登录密钥向服务管理员获取。官方 Control Plane 与插件配套模型管理接口分别使用独立地址和凭据；配套模型管理通过安装记录及接口身份核对。手工部署见 [Linux 部署说明](../deploy/README.md)。

### 独立访问官方 Control Plane

远程访问服务器上的官方页面，可使用 HTTPS 域名反向代理或 SSH 隧道。

有域名时，为官方页面配置独立 HTTPS 地址，例如 `https://memory.example.com`。无域名时，在管理员电脑执行：

```bash
ssh -N -o ExitOnForwardFailure=yes -L 127.0.0.1:9999:127.0.0.1:9999 your-user@your-server
```

替换服务器登录信息并保持终端打开，将 **Hindsight 管理地址** 填为 `http://127.0.0.1:9999`。端口改动和反向代理示例见 [部署说明](../deploy/README.md#五打开官方-control-plane)。这些设置不改变插件的 API 地址。

配套安装的登录密钥保存在服务器安装目录的 `.env`。在安装时使用的同一服务器账号下执行，`<id>` 替换为安装输出中的服务编号：

```bash
sed -n 's/^HINDSIGHT_CP_ACCESS_KEY=//p' "${HINDSIGHT_INSTALL_ROOT:-$HOME/.local/share}/astrbot-memory-<id>/.env" | tr -d '\047\042'
```

默认路径为 `~/.local/share/astrbot-memory-<id>/.env`；自定义过安装目录时，按安装输出替换命令中的路径。将输出的密钥填入官方网页登录框；连接已有服务时，向管理员获取网页登录密钥。

在 **插件设置 → 连接与访问** 复制 Hindsight 管理地址，在浏览器打开。在 **用户与记忆 → 记忆内容** 中复制 Bank ID，登录后找到对应 Bank，即可浏览、搜索、更正、删除、导入和导出。Bank 是每个用户的记忆库，首次保存聊天时由插件自动创建，无需在官方页面另建。

内容管理直接在官方 Control Plane 完成，打开面板不改变记忆模式。完整清空应使用插件 **清空记忆** 同步作废来源和待保存记录，详见 [使用指南](USAGE.md#在官方面板修改记忆)。

## 三、添加用户

1. 在 AstrBot 配置并连接 QQ 机器人，进入插件 **用户与记忆 → 添加用户**，选择平台实例。OneBot 填用户自己的 QQ 号；官方机器人填私聊 `/sid` 返回的 UID（OpenID）。
2. 点击 **添加用户**，核对实际机器人账号后点击 **确认开通**。机器人离线时名单仍会保存，连接后在用户页点击 **确认机器人身份** 重试。
3. 选择用户，点击 **读写记忆 / 只读记忆 / 停用记忆** 直接切换，之后正常聊天即可。

记忆按机器人和用户分别保存。新增、移除后重新添加或更换机器人时，须确认身份，从确认后的新消息开始记录。**移除用户** 立即撤权并移出选择器，已有记忆保留。保存连接不修改用户名单，添加和移除用户不修改服务连接。

升级前已启用的账号保留原身份、记忆库和采集时间范围；无法唯一核对的账号需重新确认。尚未聊天也可以在确认授权后选择用户和调整模式，官方页面要等首次保存、记忆库建成后才能查看该 Bank。

总开关使用 AstrBot 插件面板的启停；关闭插件后停止记录新内容、查询记忆和发送待保存记录，服务已经接受的任务仍可完成。

### QQ 官方机器人接入

在 AstrBot 的机器人管理中填写 AppID 和 AppSecret，启用 C2C 私聊事件。选择 Webhook 时，在 QQ 开放平台配置指向 AstrBot 原生回调服务的公网 HTTPS 地址，并完成回调验证和事件订阅。

在官方机器人私聊发送 `/sid`，将 Bot ID 作为平台实例 ID、UID 作为用户 OpenID，去掉外侧括号。保持 OpenID 的大小写和原值。可以参考 [官方机器人配置示例](../examples/config.qq-official.example.json)；WS 和 Webhook 使用相同的插件配置格式。

切换 WebSocket 或 Webhook 时，在 QQ 开放平台和 AstrBot 中调整连接方式，保持原实例、AppID 和使用者 OpenID，插件会继续使用已有记忆与授权。

更换实例或 AppID 后，为新账号确认授权。新旧账号的记忆分别保存，旧库在该用户的记忆库选择器中显示，可处理已有暂停或清空记忆。

## 四、服务管理

配套部署的模型配置、连接状态与服务管理位于 **插件设置**。适用更新在顶部横幅提示，可忽略该连接的目标版本；未结束的升级保留入口，不能忽略。保存模型时验证配置并重启配套服务，成功后生效；更换嵌入模型、参数或维数需要迁移已有向量数据。

**备份指南** 和升级流程中的 **查看备份步骤** 在页内显示操作步骤，并提供可复制的命令示例和文档地址。

在 **插件设置 → 服务管理 → 卸载服务** 确认删除全部记忆数据后，可生成完整卸载命令，在原安装主机执行。这会删除这套服务中所有用户的记忆，无法恢复。命令按安装标识检查目录与资源，只删除这套配套服务的容器、专属网络、数据卷和安装文件。共享镜像、Docker、AstrBot 和其他服务不属于卸载范围。插件本体在 AstrBot 插件面板卸载。

连接已有 Hindsight 时，插件仅提供连接与记忆功能，能力对照见 [README](../README.md#安装)。

## 常见问题

### 找不到「记忆管理」视图

检查 AstrBot 版本是否为 4.29.1 或更高，插件是否安装成功并处于启用状态。更新插件后可先重载，再重新打开插件详情。

### 模型列表中没有嵌入模型

到 AstrBot **模型供应商 → 嵌入** 添加 Embedding 模型，保存后返回插件，模型列表会自动更新。插件沿用供应商的连接信息。

### 模型验证或保存超时

模型验证与服务启动在后台处理，页面显示进度。网络中断后重新打开页面查看结果；处理失败时，按提示检查所选模型的地址、密钥与网络，再点击 **保存模型**。

### 供应商显示不兼容

支持的模型接口见 [模型兼容范围](SUPPORT.md#模型供应商复用)。模型类型未适配、使用多模态嵌入或请求参数冲突时，页面会显示具体原因。

### 安装命令提示无法使用 Docker

请在服务器主机的终端执行，不要在 AstrBot 容器内部执行。Docker Engine 和 Compose v2 需要安装完成，执行命令的账号需要有 Docker 使用权限。

### 安装时下载或构建失败

终端会显示 Docker 的具体错误。检查服务器到镜像仓库及软件源的网络后，重复执行同一条安装命令。重复执行沿用服务身份和数据库。

### 提示无法连接后端

配套安装需在运行这套 AstrBot 的 Docker 主机执行。已有服务请检查 API 地址、端口和网络是否可达；Docker 容器之间一般使用服务名称访问。

### 记忆检索超时

插件配置中的「记忆检索最长等待时间（秒）」默认 10 秒，可设为 0.2 到 30 秒。检索响应较慢时可适当增加。升级不会覆盖已保存的值；超时后聊天继续，保存独立进行。

在「用户与记忆」选择用户，查看最近检索时间与结果。检索超时后普通聊天继续，待保存记录仍在后台处理。

### 模型地址使用 localhost

配套记忆服务在独立容器中运行，不能直接复用指向 AstrBot 自身的 `localhost`、`127.0.0.1` 或 `::1`。请在 AstrBot 模型供应商中使用记忆容器也能访问的服务地址。Docker 中的模型可使用共享网络内的服务名称；仅监听宿主机回环地址的模型，需要先调整监听地址和容器网络。

### 提示 API Key 无效或后端未启用认证

配套安装的 Key 自动交接。连接已有服务时，使用服务 API Key，并请管理员确认已启用认证。服务 Key 与 Hindsight 网页登录 Key 不同。

### 提示执行器不支持

在所选 QQ 用户使用的 AstrBot **配置文件 → AI → Agent 执行方式**中选择 **内置 Agent**。Dify、Coze 等执行器没有接入自动记忆流程。

### 保存后还看不到记忆

账号从确认授权后的新消息开始记录，首次保存时自动创建记忆库，无需在官方页面另建。后台需要整理时间；可以在 **用户与记忆 → 记忆状态** 查看保存进度和错误，再用记忆库 ID在官方页面找到对应 Bank。群聊、媒体和命令不自动记录。确认授权后就能选择用户和设置模式，记忆为空也能操作。

### 导出 JSON 文件失败

管理员可在官方 Control Plane 使用原生导出，无需经 QQ 传输。

使用私聊 `/hindsight export` 时，AstrBot 与 OneBot 分容器可能需要配置文件回调地址。在 AstrBot **系统配置**填写 OneBot 能访问的 `callback_api_base`，例如同网络的 `http://astrbot:6185`，或由管理员设置共享文件目录。

官方机器人使用 AstrBot 原生 QQ 文件上传和 C2C 发送，不使用 OneBot 的文件回调设置。上传被拒绝、文件超出平台限制或发送失败时，检查 AstrBot 原生日志和机器人权限，或改用官方 Control Plane 导出。

### 官方机器人没有回复

在 AstrBot 检查机器人登录状态、C2C 消息接收、模型调用和发送日志。遇到 Token 超时或发送断连，可在机器人管理中重载原配置，再发送私聊确认连接恢复。

### 浏览器打开 Webhook 地址显示 Method Not Allowed

Webhook 回调路径接收 POST，浏览器直接打开可能返回 405。请在 QQ 开放平台完成回调验证，并发送私聊确认事件已到达 AstrBot。

### 提示需要恢复控制目录

按 [备份与恢复](DATA-MAINTENANCE.md#异常提示) 恢复匹配的控制目录。

### 提示 记忆库丢失、保存查询已暂停或旧更正需转存

`bank_missing` 表示已经建好的记忆库丢失，`/hindsight on` 不会重建。恢复原 Bank 后，在 **查看暂停状态** 中点击 **核对记忆库**；仍有读写暂停时再解除。决定舍弃旧记忆时，点击 **清空记忆**，清理后再开启“读写记忆”。清空无法恢复，AstrBot 聊天记录不删除。保存和查询已暂停、任务结果不明和历史更正的处理步骤见 [异常提示](DATA-MAINTENANCE.md#异常提示)。

## 高级配置

队列、召回预算和暂停与任务检查参数仍可在插件标准配置中调整。批量部署可参考 [配置示例](../examples/config.example.json)，数据搬迁见 [备份与恢复](DATA-MAINTENANCE.md)。
