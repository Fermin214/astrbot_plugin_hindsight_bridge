# 使用与管理记忆

完成设置后，直接与机器人正常聊天。插件保存私聊文字和机器人最终回复，供后续聊天查找。

新增账号需先点击 **保存连接和使用者名单**，再点击 **确认账号授权**，核对机器人账号。从名单移除并保存后撤销该用户的记忆访问权限，已有记忆保留；重新添加或更换机器人登录账号后须再次确认，仅接收确认之后的新消息。

OneBot 使用用户 QQ 号；官方机器人 WebSocket 与 Webhook 使用私聊 `/sid` 返回的用户 UID（OpenID）。各入口使用相同命令。图片和引用由 AstrBot 处理，不自动保存为记忆。

## 管理入口

打开 **Hindsight Bridge 插件详情 → 记忆管理 → 记忆与保存 → 用户记忆**，选择要管理的用户。选择旁显示记忆模式、保存进度和最近检索结果，并提供暂停保存和查询、恢复原记忆模式及重试操作；切换用户后，状态和操作一起切换。清空记忆位于该区域末尾。具体说明点击各区域右上角的问号查看。“设置”用于安装、连接、选择模型、添加使用者和管理配套服务。总开关使用 AstrBot 插件面板的启停。

在 **查看和管理记忆** 中复制“官方管理地址”和“记忆库 ID”，用浏览器打开 Hindsight 原生官方管理页面（Control Plane），登录后找到对应 Bank。这里可以浏览、搜索、更正、删除、导入和导出记忆。

**Bank 是每个用户的记忆库**，首次保存聊天时由插件创建，随后可在官方页面按编号访问。

API 地址供 AstrBot 连接服务；“官方管理地址” `control_plane_url` 供管理员浏览器访问，两者分别配置。服务器面板需要 HTTPS 域名反向代理或 SSH 隧道；浏览器中的 `127.0.0.1` 指管理员自己的电脑。路径、隧道和获取 `HINDSIGHT_CP_ACCESS_KEY` 的命令见 [安装指南](INSTALL.md#独立访问官方-control-plane)。连接已有服务时，向管理员获取网页登录密钥。

## 在官方面板修改记忆

浏览、搜索可直接进行。更正、删除、清空、重处理或导入前，在 **此用户的保存与查询** 中操作：

1. 想保留未发送记录，应在暂停保存和查询前等它们保存完成。失败记录先处理故障，再点击 **重试失败记录**。
2. 点击 **暂停保存和查询**。这会暂停新保存和记忆查询，停止发送等待中的记录和重试；服务已接受的任务仍会继续处理。
3. 点击 **检查暂停进度**，等待已接受任务完成。未发送或保存失败的记录保持暂停；决定放弃时，勾选 **放弃尚未发送或保存失败的记录（不可恢复）**，再次点击 **暂停保存和查询**。
4. 状态显示“可以修改记忆”后，在官方页面找到对应 Bank，完成修改。操作后核对用户与记忆库 ID，点击 **恢复原记忆模式**，再确认记忆模式。

页面仍有待处理任务时，刷新状态并按提示处理，等“可以修改记忆”后再操作。常见错误的处理见 [备份与恢复](DATA-MAINTENANCE.md#异常提示)。

移除使用者或更换机器人后，旧记忆显示为历史范围。管理员可暂停保存和查询或清空这些记忆，新机器人使用独立记忆库。

在官方页面删除整个 Bank 后，插件暂停该用户的记忆功能。恢复原 Bank 后点击 **恢复原记忆模式**；决定舍弃旧数据时，按清空记忆流程处理。完整步骤见 [备份与恢复](DATA-MAINTENANCE.md#在官方面板修改记忆)。

## QQ 私聊命令

命令操作当前机器人下本人的记忆。日常聊天无需逐条保存或手动搜索；收到确认过期或重发提示时，重新发送命令即可。

| 命令 | 用途 |
| --- | --- |
| `/hindsight help` | 查看帮助 |
| `/hindsight status` | 查看连接、模式、队列、暂停与清理信息 |
| `/hindsight view [页码]` | 查看本人记忆，每页 10 条，默认第 1 页 |
| `/hindsight show 记忆ID` | 从列表复制记忆 ID，查看这条记忆的详情、时间和来源 |
| `/hindsight recall 问题` | 搜索本人记忆 |
| `/hindsight background` | 只读查看本人已选知识页、开关和刷新记录 |
| `/hindsight export` | 导出本人记忆和来源材料，得到 JSON 文件 |
| `/hindsight retry` | 故障处理后重试本人的失败记录，与插件页“重试失败记录”作用相同 |
| `/hindsight cancel 任务编号` | 取消指定保存任务，编号从 `status` 取得 |

### Hindsight 原生名称

插件沿用 Hindsight 1.1.0 / 1.2.0 官方 Control Plane 的内容名称，中文与英文对应如下：

| 名称 | 用途 |
| --- | --- |
| 记忆库（Bank） | 每个用户的独立记忆范围，以 Bank ID 定位 |
| 世界事实（World Facts） | 来自外部的人、事物和事件等事实 |
| 经历（Experience） | 记忆库所属 Agent 自己的行为与经历 |
| 观察（Observations） | Hindsight 通过整合（Consolidation）从事实生成的知识 |
| 知识库 / 知识页（Knowledge Base / Knowledge Page） | 按文件夹组织、由 Hindsight 生成和更新的主题文档 |
| 心智模型（Mental Model） | 原生主题知识模型；知识页也是一种心智模型 |
| Control Plane | Hindsight 官方记忆管理面板 |

Retain 用于保存材料并提取记忆，Recall 用于召回相关记忆，Reflect 用于根据记忆生成回答和知识页。插件的“保存”“检索”“聊天时使用所选知识页”描述具体动作，不是另外的 Hindsight 内容类型。名称来源见 [官方中文界面](https://github.com/vectorize-io/hindsight/blob/v1.2.0/hindsight-control-plane/src/messages/zh-CN.json) 和 [知识页文档](https://hindsight.vectorize.io/developer/knowledge-pages)。

新材料经后台处理后出现在记忆中；查看、搜索和导出均读取官方服务。

列表和详情是有长度限制的预览，过长内容会省略。需要完整内容时，使用 `/hindsight export` 或官方 Control Plane；平台无法发送长文本或文件时，改用官方页面。

更正记忆请联系管理员，先暂停保存和查询，再到官方页面操作。

## 暂停与恢复

| 效果 | 命令 | 记录新内容 | 聊天时自动使用已有记忆 |
| --- | --- | --- | --- |
| 保存并自动使用记忆 | `/hindsight on` | 是 | 是 |
| 只自动使用已有记忆 | `/hindsight readonly` | 否 | 是 |
| 暂停保存和自动使用 | `/hindsight pause` | 否 | 否 |

“只自动使用已有记忆”和“暂停保存和自动使用”都会保留已存记忆，允许手动查看、搜索和导出；保存和查询暂停、记忆库丢失或数据恢复检查期间，这些查询也会暂停。两种模式都暂停发送等待中的记录，切回“保存并自动使用记忆”后继续保存仍有效的记录；服务已接受的任务仍可完成。这两种模式下的新聊天不补录。

记忆模式与保存和查询暂停状态分别管理。已暂停保存和查询的账号须由管理员点击「恢复原记忆模式」，再调整模式。想保留等待发送的记录，应在暂停保存和查询前切回“保存并自动使用记忆”，等它们保存完成。

## 导出

`/hindsight export` 通过 QQ 发送 UTF-8 JSON，包含本人的世界事实（World Facts）、经历（Experience）、观察（Observations）和相关源文档。单次最多 10,000 条记忆、8 MiB；数据较多时可使用官方页面导出。

个人导出不包含知识页及其历史。服务、插件运行库和最新控制库按 [完整备份](DATA-MAINTENANCE.md) 流程保存。QQ 文件上传配置见 [安装指南](INSTALL.md#导出-json-文件失败)。

## 清空记忆

管理员在 **记忆与保存 → 用户记忆** 点击 **清空此用户的记忆**，核对用户后点击 **确认清空记忆**。用户也可以在 QQ 私聊发送 `/hindsight forget`，按回复在 120 秒内发送 `/hindsight forget 确认码`。

清空会删除此用户的全部长期记忆、知识页及其历史、来源材料和待保存记录，无法恢复；AstrBot 自身的聊天记录保留。

清理期间保持暂停，服务连接恢复后会继续删除，进度可在插件页或 `/hindsight status` 查看。清理完成后，重新选择“保存并自动使用记忆”或发送 `/hindsight on`，从新消息开始积累记忆；新记忆库在首次保存聊天时自动创建。

## 可选知识页

插件可以将用户 Bank 中的一份 **知识页（Knowledge Page）** 作为临时参考传递给聊天请求，默认关闭。自动记忆召回（Recall）负责问题相关的记忆检索，知识页补充管理员选定的主题文档。知识页由 Hindsight 生成、刷新和存储，Bridge 只管理选择与传递。

### 配置

1. 在 Control Plane 选择用户的 Bank，进入 **知识（Knowledge）→ 知识页（Pages）**，在 **知识库（Knowledge Base）** 点击 **新建知识页（New page）**。填写名称和 **源查询（Source query）**，即希望此页回答的问题，创建后等待正文生成。
2. 确认来源范围和正文。需要缩短正文时，打开该页的 **心智模型选项（Mental model options）**，点击 **编辑（Edit）**，在 **概览（General）** 调低 **最大令牌数（Max Tokens）** 并保存。重新打开「心智模型选项」，在操作菜单点击 **立即完整刷新**，再确认 **执行完整刷新**，等待生成并核对正文长度；普通手动刷新可能保留原正文。`tags` 按原生过滤规则配置；使用未打标签的既有记忆时，保持标签为空。创建和刷新按 Hindsight 模型配置产生调用费用。
3. 在插件页 **记忆与保存 → 用户记忆 → 知识页（Knowledge Page）** 点击 **获取知识页列表**，选择知识页，勾选 **聊天时使用所选知识页**，再点击 **保存知识页选择**。
4. 使用 `/hindsight background` 读取已选正文、开关、刷新及失败时间。该既有命令保留兼容，不是 Hindsight 的原生功能名称。

### 自动读取与内容更新

- 知识页和 Recall 共用 `recall_max_tokens`、`context_max_chars` 与 `recall_timeout`。完整短页连同包装最多占用 `min(400, B/3)` tokens，其中 B 为本轮 token 预算；超限时整页跳过，Recall 使用原预算。
- 自动路径读取原生 `detail=content`，Hindsight 1.1.0 / 1.2.0 在该路径返回的 `is_stale` 为 null，显示为新鲜度未知。更新状态通过 Control Plane 核对。
- 正文为空时等待原生生成，持续为空时检查来源和标签；超长正文在 Control Plane 调整为短页；读取超时按服务故障流程处理。
- 点击「停止聊天时使用知识页」后不再向聊天模型传递所选页，原生知识页、选择和手动查看保留。「暂停保存和自动使用」模式只停止自动传递，手动查看保留；点击「暂停保存和查询」后，以及清空记忆期间，停止所有内容读取。重新授权或完整遗忘后重新选择。
- 内容更正、源事实删除和重处理沿用在官方面板修改记忆流程，核对 Bank 内整合/刷新任务及页内容后恢复。插件暂停期间，Hindsight 原生后台刷新按自身设置运行。

个人 JSON 导出包含世界事实、经历、观察及其引用源文档。知识页正文和版本历史随 Hindsight 数据库备份。

## 故障处理

先发送 `/hindsight status` 查看状态，将错误提示交给管理员。处理方法见 [备份与恢复](DATA-MAINTENANCE.md#异常提示)。

取消任务会停止后续发送，并继续核对已经发出的请求，已形成的记忆仍保留。任务接收或取消结果不明时保持暂停，不反复重试；需要清除所有旧材料时使用清空记忆。
