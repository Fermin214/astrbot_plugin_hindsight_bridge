# 使用与管理记忆

启用后，直接与机器人正常聊天。插件会自动保存适用的文字对话，并在后续聊天时查找相关记忆。

## 在 AstrBot 中管理

打开 **Hindsight Memory 插件详情 → 记忆管理**：

- 「运行状态」显示服务连接和各用户的后台任务。
- 「记忆管理」按用户查看、搜索和打开记忆详情，也可直接下载 JSON。
- 打开详情可提交更正。管理员提交的内容会明确记录管理员来源，与用户私聊原文区分。
- 模式可以切换为开启、只读或暂停。完整遗忘会显示用户范围，并要求再次确认；清理后记忆保持暂停。

这个视图供 AstrBot 管理员使用，可以管理已开放账号的记忆。普通使用者通过私聊命令管理自己的记忆。

## 在 QQ 私聊中管理

以下命令都在与机器人的 **QQ 私聊**中发送，只操作发消息者自己的记忆。日常聊天无需逐条保存，也无需每次手动搜索。

## 查看记住了什么

发送：

```text
/hindsight view
```

列表会显示记忆内容、类型、时间和记忆 ID，每页最多 10 条。查看第二页：

```text
/hindsight view 2
```

想看一条记忆的详细内容和来源，用列表里的完整记忆 ID 替换下面的 `记忆ID`：

```text
/hindsight show 记忆ID
```

“整合观察”是 Hindsight 从多条记忆中整理出的结果。新消息先在后台处理，因此聊天后不一定立即出现在列表中。

## 更正记错的内容

先用 `/hindsight view` 找到要更正的记忆，复制它的完整 ID，再发送：

```text
/hindsight correct 记忆ID 我现在住在杭州，以前住在上海。
```

把 `记忆ID` 替换成实际 ID，后面直接写正确内容，最多 1,000 个字符。

更正会作为新的说明用于后续记忆查询，旧内容保留来源记录。要删除自己的全部记忆，使用清空命令。

更正需要开启记录；如果之前暂停或切换成只读，先发送 `/hindsight on`。

## 暂停或恢复

| 你想要的效果 | 发送 | 是否记录新内容 | 聊天时是否自动使用已有记忆 |
| --- | --- | --- | --- |
| 正常使用 | `/hindsight on` | 是 | 是 |
| 只用已有记忆 | `/hindsight readonly` | 否 | 是 |
| 暂停自动记忆 | `/hindsight pause` | 否 | 否 |

只读和暂停都保留已经存下的记忆，也可以手动查看、搜索和导出。恢复开启后，从新的对话继续记录；暂停期间的对话不会补录。

尚未提交的记录在只读或暂停时冻结，恢复开启后继续处理；已经交给后端的任务可能仍会完成。

## 导出自己的记忆

```text
/hindsight export
```

机器人会发送一个 UTF-8 JSON 文件，包含自己的记忆、整合观察、相关来源文档和更正内容。这是个人记忆数据导出；服务器迁移与完整备份见 [备份与恢复](DATA-MAINTENANCE.md)。

单次导出最多 10,000 条记忆、文件最多 8 MiB。超过限制时按提示由维护者从后端导出。读取期间内容变化或来源缺失时，命令会提示重试或检查后端。

## 清空自己的全部记忆

先发送：

```text
/hindsight forget
```

机器人会列出清空范围并给出一个确认码。在 **120 秒内**，按回复发送：

```text
/hindsight forget 确认码
```

把 `确认码` 替换为机器人给出的值。清空会删除该插件管理的个人记忆、相关来源材料及旧任务，并进入暂停模式。后端暂时不可用时，删除会在连接恢复后继续。

想重新积累记忆，发送 `/hindsight on`。AstrBot 自己的聊天记录由 AstrBot 单独管理，清空记忆不会删除那些聊天记录。

## 手动搜索

自动记忆会在聊天时查找相关内容。想直接看搜索结果，也可以发送：

```text
/hindsight recall 我之前说过哪些饮食偏好
```

这会搜索自己的记忆并显示结果。只读和暂停模式下也可使用。

## 出现问题时

发送 `/hindsight status`，查看连接、模式、待处理数量和错误提示。常见处理方式见 [安装指南](INSTALL.md#常见问题)。

| 命令 | 用途 |
| --- | --- |
| `/hindsight help` | 查看命令提示 |
| `/hindsight retry` | 在故障处理后重试自己的失败任务 |
| `/hindsight cancel 任务编号` | 取消指定任务，任务编号从 `status` 中取得 |

取消任务会停止后续提交，并继续处理已经发出的请求结果；已经形成的记忆会保留。需要清除全部记忆时使用 `/hindsight forget`。
