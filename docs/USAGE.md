# 使用指南

配置好服务并启用用户后，正常跟机器人私聊即可，不需要任何额外操作。插件会在后台保存私聊文字和机器人的最终文字回复，并在下次对话时自动调取相关记忆。

## 面板概览

在 AstrBot 打开 **Hindsight Bridge 插件详情 → 记忆管理**，面板分为 **用户与记忆** 与 **插件设置** 两个页签。

### 用户与记忆

- **顶部用户栏**：选择要管理的用户，或点击 **+ 添加用户** 绑定新账号。下方展示当前机器人账号、**Bank ID**（可一键复制）以及历史机器人切换留下的旧库选择器。
- **记忆模式与状态总览**：
  - 点击 **读写记忆 / 只读记忆 / 停用记忆** 即时生效。
  - 状态区显示 **已保存**（已确认入库的用户消息与回复条数）、**待保存**、**保存失败**（失败时会出现 **重试保存**）以及 **最近检索** 的结果与耗时。如果最近一条名单内的私聊被跳过，也会在这里显示原因（重载后清空）。
- **聊天记忆配置**（按当前用户独立生效，各卡片修改后需分别点击保存）：
  - **细节记忆读取方式**：选择 **自动召回** 或 **按需工具**。
  - **聊天参考与保存**：配置记忆提示词、检索类别（世界事实 / 经历 / 观察）、检索预算与条数上限、是否排除机器人回复、是否允许引用回复或带链接的私聊只读检索、是否保存助手回复，以及使用记录的保留轮数。左下角 **查看使用记录** 可检查每轮真实发给模型的原文。
  - **知识页（Knowledge Pages）**：通过开关控制聊天时是否附带所选知识页，在下拉框添加并排序最多 8 篇主题文档，支持一键刷新列表或跳转调整长度上限。
  - **Reflect 综合推理**：按用户开关 Reflect，并设置等待超时；遇到挂起卡死时可在底栏点击 **解除 Reflect 阻塞**。
- **危险操作**：提供 **移除用户**（仅撤销权限，保留记忆数据）与 **清空记忆**（彻底删除该用户记忆库）。

### 插件设置

服务连上后，页面优先显示 **全局记忆参数**，下方依次为 **Hindsight 服务连接** 与 **部署与迁移信息**（未连接服务前，**Hindsight 服务连接** 会置顶方便配置）。

**全局记忆参数**对所有用户生效，保存即刻生效：

| 分组 | 参数 | 默认值与范围 | 说明 |
| --- | --- | --- | --- |
| 检索与上下文 | 记忆参考总上限 | 1200 token，256–8192 | 知识页、检索结果与提示共用的总预算（同时受 4000 字符默认上限约束） |
| 检索与上下文 | 检索最长等待 | 10 秒，0.2–30 秒 | 超时后跳过本次检索，聊天照常继续 |
| 检索与上下文 | 查询语句长度上限 | 380 token，32–400 | 发给 Hindsight 的查询文本上限，优先保留最新用户发言 |
| 检索与上下文 | 分词编码 | `o200k_base` | 用于计算查询与记忆参考的 tiktoken 编码名 |
| 知识页 | 知识页长度上限 | 400 token，64–8192 | 单篇知识页的独立上限，超限整篇跳过不截断 |
| 知识页 | 知识页最长等待 | 1 秒，0.05–10 秒 | 读取全部已选知识页的等待上限（实际不超过检索等待的四分之一） |
| 保存队列与过滤 | 待保存记录上限 | 10000 条 | 积压达到上限后暂拒新记录，等排空后自动恢复 |
| 保存队列与过滤 | 待保存容量上限 | 64 MiB | 本地待保存正文总容量上限 |
| 保存队列与过滤 | 额外排除的命令前缀 | 留空，逗号分隔 | 以 `/` 开头的命令始终不记；需要排除 `!`、`#` 等其他前缀时在此补充 |

页面每隔几秒自动刷新状态，并会保留未保存的编辑草稿；若检测到其他标签页修改了设置，页面会提示重新加载以免覆盖。底部的 **部署与迁移信息** 展示服务识别码、归属识别码与控制目录路径，供迁移服务器时核对。

## 在官方面板修改记忆

Hindsight 官方记忆面板（Control Plane）负责浏览、搜索、更正、删除单条记忆和导入导出。

从 **插件设置 → Hindsight 服务连接** 复制 **Hindsight 管理地址** 在浏览器打开，再从 **用户与记忆** 复制目标用户的 **Bank ID** 即可定位记忆库。日常增删改直接在官方页面完成，不需要暂停插件；访问与密钥获取见 [安装指南](INSTALL.md#独立访问官方-control-plane)。

- **多机器人换号**：同一用户如果更换了机器人账号，旧机器人攒下的记忆库会归入顶部的 **记忆库** 下拉框以便查看或清空，不会直接并入新机器人。
- **整库删除提醒**：在官方 Control Plane 直接删掉整个 Bank 会触发插件报 `bank_missing` 并暂停读写。想彻底清除某个用户的记忆，请直接用面板的 **清空记忆** 按钮，让插件一并清理本地待办队列和来源记录。若误删了 Bank，可先恢复备份再点 **查看暂停状态 → 核对记忆库**。
- **恢复暂停状态**：服务升级或异常后若出现 **查看暂停状态**，点击后页面会自动核对在途任务；确认无误即可 **解除读写暂停**，若存在未发送或确认失败的积压记录且不需要保留，可勾选后 **放弃记录**。

## 私聊命令

私聊发送以下命令时，只作用于当前说话者自己名下的记忆（命令本身不会记入记忆）：

| 命令 | 用途 |
| --- | --- |
| `/hindsight help` | 查看可用命令 |
| `/hindsight status` | 查看连接状态、当前模式、待保存队列和暂停原因 |
| `/hindsight on` | 开启读写记忆 |
| `/hindsight readonly` | 切为只读模式（保留现有记忆并继续召回，不再保存新消息） |
| `/hindsight pause` | 停用记忆（停止保存和自动召回） |
| `/hindsight forget` | 发起清空个人记忆，按回复在 120 秒内输入确认码完成 |

浏览、检索、修改和导出记忆使用 Hindsight Control Plane；已交付的参考原文和知识页在插件 **使用记录** 中查看。保存失败记录在用户页重试。0.5.0 移除 `correct`、`view`、`show`、`export`、`recall`、`background`、`retry`、`cancel`，不再提供单项任务私聊取消；清空记忆会作废积压并删除整个个人 Bank。

### 术语对照

插件沿用 Hindsight 1.1.0 / 1.2.0 官方 Control Plane 的名称：

| 术语 | 含义 |
| --- | --- |
| 记忆库（Bank） | 每个机器人与用户组合对应的独立记忆空间，以 Bank ID 标识 |
| 世界事实（World Facts） | 对话中提取出的外部人物、事件等客观事实 |
| 经历（Experience） | 机器人自身参与的行为与交互经历 |
| 观察（Observations） | Hindsight 整合多条事实后提炼出的长期结论 |
| 知识页（Knowledge Page） | 在知识库（Knowledge Base）中按主题自动维护的文档 |
| 心智模型（Mental Model） | 原生主题知识模型，知识页也属于心智模型 |
| Control Plane | Hindsight 官方管理后台 |

## 聊天参考与使用记录

在 **用户与记忆 → 聊天参考与保存** 中可以精细调整回忆效果：

- **记忆提示**：放在记忆参考前面给模型看（上限 256 token），与知识页和细节记忆共用整段预算。默认、自定义和清空分别生效，清空并保存后不加固定提示。
- **细节记忆类别与条数**：默认勾选世界事实、经历、观察，每条消息最多带入 12 条。取消全部类别或把上限设为 `0` 会关闭聊天自动检索。
- **检索预算**：低（更快）、中（默认平衡）、高（检索更深）。
- **只参考用户发言**：开启后忽略纯机器人发言的记忆，只保留用户说过的话以及来源混合/未知的条目。
- **保存助手回复**：默认开启；关闭后，新对话只记录用户消息，已保存的历史助手记忆仍然可用。
- **引用回复或带链接的私聊也检索**：默认关闭。开启后，对已开通用户的引用回复、以及 Telegram 带链接或 `@` 提及的私聊文字，会继续读取已有记忆、知识页和按需工具，但**这类消息和机器人的回复都不会保存为新记忆**。群聊、媒体和转发消息依然排除。
- **使用记录**：默认保留最近 30 轮，轮次列表显示知识页、细节记忆和工具调用数量。弹窗的 **参考内容 / 发给 AI 的原文 / 原始 JSON** 三个页签分别查看正文卡片、真实交付原文和整轮数据。卡片可复制 ID，配合 Hindsight Control Plane 查找记录。页名与新鲜度固定为交付时的快照；调低轮数删除超出部分，设为 `0` 关闭并清空记录。

## 可选知识页

知识页适合存放“用户画像”“常用偏好”“长期项目背景”等稳定主题，由 Hindsight 负责生成和定时刷新，Bridge 负责按顺序放进聊天上下文。

### 配置步骤

1. 在官方 Control Plane 打开用户的 Bank，进入 **知识（Knowledge）→ 知识页（Pages）**，点击 **新建知识页（New page）**，填好名称和 **源查询（Source query）** 后等待生成。
2. 如果正文太长导致被跳过，在官方页面打开该页的 **心智模型选项（Mental model options）→ 编辑（Edit）**，在 **概览（General）** 调低 **最大令牌数（Max Tokens）**，保存后回到菜单点击 **立即完整刷新 → 执行完整刷新**。若只使用普通记忆（未打标签），`tags` 保持留空即可。
3. 回到插件面板 **用户与记忆 → 知识页（Knowledge Pages）**，从下拉框添加页面（最多 8 篇），用 **上移 / 下移** 调整顺序，打开 **聊天时附带所选知识页** 开关后点击 **保存**。
4. 想临时停用但保留配置顺序，直接关闭开关再点 **保存** 即可；交付的页面正文在 **使用记录** 中查看。

列表会展示每篇知识页包含包装后的实际 token 数和超限提示，也会单独标出上次聊天时该页是否被正常放入（单篇超过「知识页长度上限」，或加上后超出「记忆参考总上限」/ 4000 字符默认总上限时，会整篇跳过，不会截断）。目录中的「有新记忆待刷新」只代表目录元数据提示，具体刷新进度以 Control Plane 为准。

## 按需记忆工具

如果不想每句话都硬塞一段记忆，可以把 **细节记忆读取方式** 切为 **按需工具** 并保存，让 AstrBot 的 Agent 自己决定什么时候去查记忆：

| 工具名 | 作用 |
| --- | --- |
| `hindsight_bridge_search_pages` | 按关键字搜索用户的知识页（最多返回 5 条摘要） |
| `hindsight_bridge_read_page` | 按行分段读取某篇知识页的完整正文 |
| `hindsight_bridge_recall` | 调用 Hindsight 检索细节记忆并带回来源和时间 |
| `hindsight_bridge_page_sources` | 查看知识页引用的原始来源编号 |
| `hindsight_bridge_page_history` | 查看知识页最近 5 次刷新或失败记录 |

每条用户消息最多允许调用 4 次记忆工具，单次读取限时 3 秒（且不超过检索最长等待），单次和累计输出受全局字符、token 与字节上限约束（累计最高两倍记忆参考总上限、16 KiB）；额度用完后工具会从本轮移除，让模型直接回答。注意如果当前对话配置了不支持工具调用的模型、或者使用了模型回退列表、子代理交接等情况，面板会提示按需工具不可用，切回 **自动召回** 即可。

## Reflect

在 **用户与记忆 → Reflect 综合推理** 中可以按用户开启 **Reflect**（默认关闭，最长等待默认 12 秒，可设 3–30 秒）。

与普通 Recall 只返回零散片段不同，Reflect 会让 Hindsight 直接用它的记忆模型综合多条记忆回答复杂问题，再把结论和来源交还给聊天模型，因此每次触发都会额外消耗一次 Hindsight 侧的模型调用，并与记忆工具共用每轮 4 次的调用配额。

如果等待到期前 Hindsight 还没答完，普通聊天会直接继续（晚到的结果不会插回当前消息，但后端仍会跟踪请求状态直到完成）。

**解除 Reflect 阻塞**：由于 Hindsight 1.1.0 / 1.2.0 没有提供查某个 Reflect 请求是否跑完的接口，若遇到断网或进程重启导致请求状态未知，对应记忆库的 Reflect 发起、解除暂停和清空记忆都会暂时卡住等待（其他用户不受影响）。管理员确认 Hindsight 已重启或确实没有运行中的 Reflect 任务后，可在卡片底栏（或 **查看暂停状态**）点击 **解除 Reflect 阻塞**，选择记忆库并勾选确认即可恢复。

> 0.4.0 的人工解阻记录与请求状态保存在格式 7 控制库中，升级后无法直接降级回旧版插件；详见 [数据维护](DATA-MAINTENANCE.md#reflect-与控制库格式)。

## 故障处理

遇到无法保存或检索报错时，先发送 `/hindsight status` 或查看总览卡提示，再对照 [异常提示](DATA-MAINTENANCE.md#异常提示) 排查。

保存失败记录在插件记忆管理页重试。需要作废积压并删除已有内容时，使用 **清空记忆**。
