# 使用与管理记忆

完成设置后，直接与机器人正常聊天。插件保存私聊文字和机器人最终回复，供后续聊天查找。

新增账号需先保存设置，再点击 **确认账号授权**，核对当前机器人账号。移除账号立即撤权；重新添加或更换机器人登录账号后须再次确认，仅接收确认之后的新消息。

OneBot 使用用户 QQ 号；官方机器人 WebSocket 与 Webhook 使用私聊 `/sid` 返回的用户 UID（OpenID）。各入口使用相同命令。图片和引用由 AstrBot 处理，不自动保存为记忆。

## 管理入口

打开 **Hindsight Bridge 插件详情 → 记忆管理 → 运行管理 → 用户记忆**，选择要管理的用户。这里可以调整记忆模式、查看保存进度、重试失败记录、开始维护和清空记忆。具体说明点击各区域右上角的问号查看。“设置”用于安装、连接、选择模型、添加使用者和维护配套服务。总开关使用 AstrBot 插件面板的启停。

在 **查看和管理记忆** 中复制“官方管理地址”和“记忆库编号”，用浏览器打开 Hindsight 1.1.0 原生官方管理页面（Control Plane），登录后找到对应 Bank。这里可以浏览、搜索、更正、删除、导入和导出记忆。

**Bank 是每个用户的记忆库**，首次保存聊天时由插件自动创建，无需在官方页面另建。尚未保存过聊天时，官方页面可能还找不到该编号。

API 地址供 AstrBot 连接服务；“官方管理地址” `control_plane_url` 供管理员浏览器访问，两者分别配置。服务器面板需要 HTTPS 域名反向代理或 SSH 隧道；浏览器中的 `127.0.0.1` 指管理员自己的电脑。路径、隧道和获取 `HINDSIGHT_CP_ACCESS_KEY` 的命令见 [安装指南](INSTALL.md#独立访问官方-control-plane)。连接已有服务时，向维护者获取网页登录密钥。

## 官方内容维护

浏览、搜索无需维护。在官方页面更正、删除、清空、重处理或导入等修改操作前，在 **记忆保存与维护** 中操作：

1. 想保留未发送记录，应在开始维护前等它们保存完成。失败记录先处理故障，再点击 **重试失败记录**。
2. 点击 **开始维护**。这会暂停新保存和记忆查询，停止发送等待中的记录和重试；服务已接受的任务仍会继续处理。
3. 点击 **刷新维护状态**，等待已接受任务完成。未发送或保存失败的记录在维护中不会自动保存；决定放弃时，勾选 **放弃尚未发送或保存失败的记录（不可恢复）**，再次点击 **开始维护**。放弃的记录以后不会补存。
4. 状态显示“可以修改记忆”后，在官方页面找到对应 Bank，完成修改。操作后核对用户与记忆库编号，点击 **结束维护并恢复**，再确认记忆模式。

页面仍有待处理任务时，刷新状态并按提示处理，等“可以修改记忆”后再操作。常见错误的处理见 [数据维护](DATA-MAINTENANCE.md#异常提示)。

移除使用者或更换机器人后，旧记忆显示为历史范围。管理员可维护或清空这些记忆，新机器人使用独立记忆库。

在官方页面删除整个 Bank 后，插件会暂停该用户的记忆功能，不会自动重建。可恢复原 Bank 后点击 **结束维护并恢复**；决定舍弃旧数据时，按清空记忆流程处理。完整步骤见 [数据维护](DATA-MAINTENANCE.md#官方内容维护)。

## QQ 私聊命令

命令操作当前机器人下本人的记忆。日常聊天无需逐条保存或手动搜索；收到确认过期或重发提示时，重新发送命令即可。

| 命令 | 用途 |
| --- | --- |
| `/hindsight help` | 查看帮助 |
| `/hindsight status` | 查看连接、模式、队列、维护与清理信息 |
| `/hindsight view [页码]` | 调用官方只读 API 查看本人记忆，每页 10 条 |
| `/hindsight show 记忆ID` | 查看官方记忆详情、类型、时间和来源 |
| `/hindsight recall 问题` | 搜索本人记忆 |
| `/hindsight export` | 从官方 API 导出本人事实、整合记忆与源文档 |
| `/hindsight retry` | 故障处理后重试本人的失败记录，与插件页“重试失败记录”作用相同 |
| `/hindsight cancel 任务编号` | 取消指定保存任务，编号从 `status` 取得 |

“整合记忆”是 Hindsight 从多条记忆中整理出的结果。聊天材料在后台处理，不会立即显示。查看、搜索和导出均使用官方服务中的记忆。

列表和详情是有长度限制的预览，过长内容会省略。需要完整内容时，使用 `/hindsight export` 或官方 Control Plane；平台无法发送长文本或文件时，改用官方页面。

更正记忆请联系管理员，先开始维护，再到官方页面操作。

## 暂停与恢复

| 效果 | 命令 | 记录新内容 | 聊天时自动使用已有记忆 |
| --- | --- | --- | --- |
| 正常记忆 | `/hindsight on` | 是 | 是 |
| 只用已有记忆 | `/hindsight readonly` | 否 | 是 |
| 暂停记忆 | `/hindsight pause` | 否 | 否 |

“只用已有记忆”和“暂停记忆”都会保留已存记忆，允许手动查看、搜索和导出；维护、记忆库丢失或数据恢复检查期间，这些查询也会暂停。两种模式都暂停发送等待中的记录，切回“正常记忆”后继续保存仍有效的记录；服务已接受的任务仍可完成。这两种模式下的新聊天不补录。

记忆模式与维护状态分别管理。`/hindsight on` 不能结束维护或找回丢失的记忆库；管理员需先完成维护恢复。想保留等待发送的记录，应在开始维护前切回“正常记忆”，等它们保存完成。

## 导出

`/hindsight export` 通过 QQ 发送 UTF-8 JSON，包含本人的事实、整合记忆和相关源文档。单次最多 10,000 条记忆、8 MiB；数据较多时可使用官方页面导出。

个人 JSON 不包含上传队列、AstrBot 聊天历史、独立控制库或全部服务配置，不能替代 [完整备份](DATA-MAINTENANCE.md)。QQ 文件上传配置见 [安装指南](INSTALL.md#导出-json-文件失败)。

## 清空记忆

管理员在 **运行管理 → 用户记忆 → 记忆保存与维护** 点击 **清空此用户的记忆**，核对用户后点击 **确认清空记忆**。用户也可以在 QQ 私聊发送 `/hindsight forget`，按回复在 120 秒内发送 `/hindsight forget 确认码`。

清空会删除此用户的全部长期记忆、来源材料和待保存记录，无法恢复；AstrBot 自身的聊天记录保留。

清理期间保持暂停，服务连接恢复后会继续删除，进度可在插件页或 `/hindsight status` 查看。清理完成后，重新选择“正常记忆”或发送 `/hindsight on`，从新消息开始积累记忆；新记忆库在首次保存聊天时自动创建。

## 故障处理

先发送 `/hindsight status` 查看状态，将错误提示交给管理员。处理方法见 [数据维护](DATA-MAINTENANCE.md#异常提示)。

取消任务会停止后续发送，并继续核对已经发出的请求，已形成的记忆仍保留。任务接收或取消结果不明时保持暂停，不反复重试；需要清除所有旧材料时使用清空记忆。
